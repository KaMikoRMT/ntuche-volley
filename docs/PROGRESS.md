## 判斷紀錄

規格沒寫清楚、自己決定的地方（日期、階段、決定、理由）。

- 2026-10-19・P1・**資料模型新增的欄位**（規格沒有，但功能需要）：
  - `Match.curSet`（目前在第幾局，0 起算）：v5 可以自由切換局數，事件流本身看不出來「現在在哪一局」。
  - `Match.timer = { ms, since }`：v5 的計時器要在重新整理後還原。
  - 待確認事件多一個 `ts`（紀錄當下的計時器字串，如 `12:03`；計時器沒在跑就沒有）：v5 的比分軌跡要標時間，而事件的 `t` 是牆上時間，算不回計時器時間。
  - 事件種類多一個 `{ k: 'lineup', lineup }`：6.4 的「直接編輯目前號位」需要能把輪轉狀態整個蓋掉，且要能用「復原」刪掉。
- 2026-10-19・P1・**`matches_conflict`** 存成 `{ [conflictId]: { id, matchId, at, match } }`，而且整份備份會帶著它（匯出再匯入才會「資料完全相同」）；單場分享不帶。
- 2026-10-19・P1・**什麼算「兩邊都有改過」**：同一場比賽 `updatedAt` 不同時，若其中一份的事件紀錄完全包含另一份（只是記得比較多，例如接力記錄），就當成單純更新，不算衝突；只有兩邊各記各的（事件 ID 對不起來）才算衝突，保留 `updatedAt` 較新的一份，另一份放進暫存區。
- 2026-10-19・P1・**匯入不覆蓋設定**：只有本機是空的（沒有任何球員／賽季／隊伍／比賽）才帶入檔案裡的設定；`deviceId`、`lastBackupAt` 一律保留本機的。
- 2026-10-19・P1・**匯出時才更新「上次匯出」**：單場分享不算備份。
- 2026-10-19・P1・**分享選單只在手機上優先使用**：桌機的 `navigator.share` 會跳出系統分享視窗，不方便；桌機直接下載。
- 2026-10-19・P1・**拿掉 v5 的 Google Fonts 連結**：整個程式要離線、`file://` 也能用，外部資源只留 html2canvas／jsPDF；比分數字改用系統的窄體字（`Arial Narrow` 等）當後備。
- 2026-10-19・P1・**統計細節**：接發、防守指標只計「已覆盤」的球（賽中的「接球失分」「防守失分」也只在該球已覆盤時才算進去，否則到位率會偏低）；有追蹤輪轉的局，沒發過球的人發球總數是 0，沒追蹤輪轉才是「—」；進行中這一球已記的「攻擊被守起」也算進攻擊總數；「攻擊被守起」事件的細項固定記 `spike`（規格的 `spike/tip` 只有一個按鈕，沒有區分）。
- 2026-10-19・P1・**球員「出賽」的定義**：出現在先發陣容、換人、或任何事件裡的球員（只在「今日登錄」但沒上場的不算）。
- 2026-10-19・P1・P2、P3 會用到的純函式（隊伍、快速匯入、輪轉、彈窗過濾、紀錄表資料）也先放進 core 並寫了測試，所以 P1 的測試數量比 P1 範圍多。
